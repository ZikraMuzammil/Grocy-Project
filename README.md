# Grocy – Grocery Shopping & Management System

Grocy is a web-based grocery shopping and management system designed to provide customers with a convenient online shopping experience while helping store administrators manage products, orders, inventory, sales, and customers.

## Features

### Customer Features

* Browse grocery products
* View products by category
* Search and explore products
* Add products to cart
* Update cart quantities
* Place orders
* Make payments
* View order details and order status

### Admin Features

* Admin dashboard
* Product management
* Inventory and stock management
* Order management
* Sales dashboard
* Customer management
* Analytics and reports
* Shop and team management

## Product Categories

* Bakery & Dairy
* Fresh Products
* Snacks & Biscuits
* Grocery Items
* Household Products
* Frozen Foods
* Personal Care
* Pet Products
* Other Grocery Products

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* JavaScript DOM Manipulation
* Local Storage
* Responsive Web Design

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/ZikraMuzammil/Grocy-Project.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

For the best development experience, the project can be opened using **Visual Studio Code** with the **Live Server** extension.

## Purpose

The main purpose of Grocy is to demonstrate the design and development of an online grocery shopping platform with customer-facing shopping features and administrative management functions.
